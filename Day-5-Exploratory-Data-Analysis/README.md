# Day 5 - Exploratory Data Analysis (EDA)

## 📌 Objective
The objective of this task is to perform Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The analysis helps understand the dataset by identifying patterns, trends, distributions, relationships, and outliers through statistical summaries and visualizations.

---

## 📂 Dataset
- **Dataset:** Titanic Dataset
- **File:** `titanic.csv`

---

## 🛠️ Tools & Libraries Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

---

## 📊 Analysis Performed

The following EDA techniques were applied:

- Loaded and explored the dataset
- Displayed first few records using `head()`
- Checked dataset information using `info()`
- Generated statistical summary using `describe()`
- Analyzed categorical variables using `value_counts()`
- Created Histogram
- Created Box Plot
- Created Scatter Plot
- Generated Correlation Heatmap
- Created Pair Plot
- Identified trends, relationships, and outliers

---

## 📈 Key Findings

- Most passengers were between 20 and 40 years of age.
- The Age column contains a few outliers representing elderly passengers.
- A weak relationship was observed between Age and Fare.
- The correlation heatmap showed mostly weak to moderate relationships among numerical features.
- Pair Plot provided a comprehensive visualization of feature distributions and relationships.
